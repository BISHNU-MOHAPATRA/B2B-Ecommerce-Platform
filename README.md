# B2B-Ecommerce-Platform

Dynamic E-Commerce Promotion & Inventory Engine

Description
This project is developed as part of the Sruti Intellect Systems Intermediate Software Engineering Assessment.

The system manages product inventory, validates stock availability, applies bulk purchase discounts, processes coupon-based discounts, and updates inventory after successful order execution.

Features
- Object-Oriented Programming (OOP)
- Encapsulation using private attributes
- Inheritance and Method Overriding
- Stock Validation
- Bulk Pricing Discount (10%)
- Perishable Product Discount (20%)
- Coupon Discount (15%)
- Inventory Update after Order Processing
- Exception Handling

Technologies Used
- Python 3

Classes
Product
- Stores product information
- Validates price and stock values
- Manages inventory updates

 OrderProcessor
- Validates stock availability
- Calculates discounts
- Processes orders
- Updates inventory
